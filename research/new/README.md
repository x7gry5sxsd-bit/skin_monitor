## Планка «работает»

Идея проходит, если выполнено всё сразу:

- результат положительный после всех издержек: комиссии, проскальзывания и фандинга;
- t ≥ 2.5;
- обе половины выборки в плюсе;
- худший случай укладывается в допустимую просадку $100–150;
- идея исполнима на нашей инфраструктуре: Gate через API с Render или Polymarket вручную.

### Два эффекта реальны, но нам недоступны

- **Фандинг Binance (п. 7).** Сразу после расчёта с сильно отрицательной ставкой бессрочник Binance падает: держатели лонгов забирают фандинг и выходят. Эффект виден на десятках тысяч событий. Но он живёт на самом Binance. На Gate его нет (пп. 8–9). Фьючерсный API Binance с серверов бота недоступен, обходить ограничение мы не стали.
- **Финансовые рынки Polymarket (п. 11).** У сильного фаворита за последние часы середина книги отстаёт от цены бессрочника примерно на 5 ц. Купить по этой цене нельзя: у большинства рынков спред 35–60 ц.
